# AI PROJECT CONTEXT

## Project Status

This is a reusable AI hackathon development template.

The actual project will be defined after the problem statement is received.

## Default Frontend Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Lucide React
- React Router
- Recharts
- Axios

## Default Backend Stack

Use only when required:

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy

## Development Philosophy

The project must prioritize:

1. Working functionality
2. Clear user experience
3. Good visual design
4. Fast implementation
5. Maintainable code

Do not over-engineer the project.

## AI Development Rules

- Inspect the existing repository before making changes.
- Understand existing architecture before modifying it.
- Do not unnecessarily rewrite working code.
- Do not change the technology stack without approval.
- Do not hardcode API keys or secrets.
- Use environment variables for secrets.
- Reuse components where possible.
- Keep components reasonably modular.
- Prioritize core functionality over optional features.
- Test important functionality before declaring a task complete.
- Fix existing errors before adding unnecessary complexity.
